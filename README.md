# JobPilot

Parse your resume on this device. Search real listings on LinkedIn, Indeed, Glassdoor, Google Jobs and other boards. Fill application screens with a bookmarklet built from your resume. Nothing is uploaded. Applications are not submitted for you.

```bash
npm install
npm run dev
```

1. Drop in a PDF, DOCX, or paste text.
2. Open a board search (or drag **JobPilot Fill** to bookmarks).
3. On the live application page, click the bookmark, review fields, submit yourself.
